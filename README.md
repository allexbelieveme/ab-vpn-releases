# ab.VPN — готовые версии

VPN-клиент для **Windows** и **Android** (телефон и планшет).

**Скачать последнюю версию:** [Releases](../../releases/latest)

- `ab.VPN.exe` — Windows 10/11 (один файл, ничего устанавливать не нужно)
- `ab.VPN.apk` — Android 8 и новее
- `version.json` — сведения для автообновления

Установленные программы находят новые версии здесь сами: на главной появляется
«Доступна ab.VPN …», кнопка «Обновить» скачивает файл, сверяет контрольную сумму и ставит его.
